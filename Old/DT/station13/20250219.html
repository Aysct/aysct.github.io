本文所有 ≡ 均在 mod2 意义下讨论。

分析

考虑本质不同的操作只有：(a,b),(−a,b),(b,a),(−b,a)，剩下的操作可以通过使操作次数取负数得到。

于是，(a,b) 可行当且仅当：

{a(x1−x2)+b(x3−x4)=1a(x3+x4)+b(x1+x2)=0

有解。

我们换元，把四个括号换成 k1∼k4。显然 2|(k1+k4),2|(k2+k3)。

转化后有充分必要条件：

ak1+bk2=1ak3+bk4=0k1≡k4k2≡k3

注意到这里有有关 k 的限制。我们当然是需要一些只关于 a、b 的充分必要的限制。所以我们考虑出发找一些必要条件。

只考虑前面的方程的话，这是两个互不相干的不定方程，所需条件为 gcd(a,b)=1。

如果这个条件充分，由于：

ak1+bk2=1⇒{k1=x0+nbk2=y0−naak3+bk4=0⇒{k3=nbk4=−na

应该能构造出 n∗ 使得对于任意 (a,b)|gcd(a,b)=1 有：

x0+n1b+n2a≡0y0−n1a−n2b≡0

假设 a≡b，则：

x0+(n1+n2)a≡0y0−(n1+n2)a≡0

假设 x0≢y0，则上式也就不成立了，故此条件不充分。

再考虑剩下两个式子，我们直接把方程模 2：

(a−b)(k1−k2)≡1

显然要有 a−b≡k1−k2≡1。于是又导出一个限制：a≢b(mod2)。

此时我们发现，上面关于充分性的证伪中关键的一步被补充了。我们假设 a、b 中是奇数的那个数是 v，则有如下证明：

类似前面的证明，有 n∗ 使得：

x0+n1b+n2a≡0y0−n1a−n2b≡0

根据假设，式子变形为：

x0+nxk≡0y0−nyk≡0

显然我们可以通过构造 n∗ 的值使得后半部分出现 (x,y)∈{0,1}×{0,1} 的所有可能，故上式成立。所以是充分的。

于是我们得到了充分必要条件：gcd(a,b)=1∧a≢b。

计数

于是计数就是：

∑a=1n∑b≢a,1≤b≤n[gcd(a,b)=1]

或许会想直接拆解莫反，最后看起来直接整除分块了。但是这样有个问题，d≡1 不好搞。于是我们规避一下：

∑a=1n∑b≢a,1≤b≤n[gcd(a,b)=1]=2∑a=0⌊n−12⌋∑b=1⌊n2⌋[gcd(2a+1,2b)=1]

显然的一点是，奇数没有约数 2，故我们可以将 2b 直接变为 b，规模减半。

于是我们有了一个新的思路：奇数转换为偶数。

∑a=0⌊n−12⌋∑b=1⌊n2⌋[gcd(2a+1,b)=1]=∑b=1⌊n2⌋∑a=1n[gcd(a,b)=1]−∑b=1⌊n2⌋∑a=1⌊n2⌋[gcd(2a,b)=1]=∑b=1⌊n2⌋∑a=1n[gcd(a,b)=1]−∑b=0⌊⌊n2⌋−12⌋∑a=1⌊n2⌋[gcd(2b+1,a)=1]

如果我们记 f(n,m)=∑a=0⌊n−12⌋∑b=1⌊m2⌋[gcd(2a+1,b)=1]，s(n,m)=∑b=1n∑a=1m[gcd(a,b)=1]，则可以得到一个式子：

f(n,m)=s(⌊m2⌋,n)−f(⌊m2⌋,n)

可知：f 会以指数级别降低，假设我们可以在 O(T) 的时间计算 f，则可以 O(Tlog⁡n) 的算出 f。

s(n,m)=∑b=1n∑a=1m[gcd(a,b)=1]=∑1≤d,d≤n,d≤mμ(d)⌊nd⌋⌊md⌋

杜教筛可以做到 O(n2/3+n)。

总时间复杂度就是 O(n23+nlog⁡n)。

实现

#include<bits/stdc++.h>
#define ul unsigned long long
#define int long long
const int B=1e7;
using namespace std;
int pri[B+5],cnt;
ul mu[B+5],s[B+5];
bool vis[B+5];
void init(){
    mu[1]=1;
    for(int i=2;i<=B;i++){
        if(!vis[i]){
            pri[++cnt]=i;
            mu[i]=-1;
        }
        for(int j=1;j<=cnt;j++){
            if(1ll*i*pri[j]>B)break;
            vis[i*pri[j]]=1;
            if(i%pri[j]==0)break;
            mu[i*pri[j]]=-mu[i];
        }
    }
    for(int i=1;i<=B;i++)s[i]=s[i-1]+mu[i];
}
unordered_map<int,int> mp;
ul summu(int n){
    if(n<=B)return s[n];
    if(mp.count(n))return mp[n];
    ul res=0;
    for(int l=2,r;l<=n;l=r+1){
        r=n/(n/l);
        res+=summu(n/l)*(r-l+1);
    }
    res=1-res;
    return mp[n]=res;
}
ul S(int n,int m){
    if(n>m)swap(n,m);
    ul res=0;
    for(int l=1,r;l<=n;l=r+1){
        r=min(n/(n/l),m/(m/l));
        res+=(summu(r)-summu(l-1))*(n/l)*(m/l);
    }
    return res;
}
ul f(int n,int m){
    if(!n||!m)return 0;
    return S(m/2,n)-f(m/2,n);
}
int T,n;
signed main(){
    init();
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    cin>>T;
    while(T--){
        cin>>n;
        cout<<f(n,n)*2<<'\n';
    }
}
