## Luogu P6860 象棋与马

本文所有 $\equiv$ 均在 $\bmod 2$ 意义下讨论。

### 分析

考虑本质不同的操作只有：$(a,b),(-a,b),(b,a),(-b,a)$，剩下的操作可以通过使操作次数取负数得到。

于是，$(a,b)$ 可行当且仅当：
$$
\begin{cases}
a(x_1-x_2)+b(x_3-x_4)=1\\
a(x_3+x_4)+b(x_1+x_2)=0
\end{cases}
$$
有解。

我们换元，把四个括号换成 $k_1 \sim k_4$。显然 $2|(k_1+k_4),2|(k_2+k_3)$。

转化后有充分必要条件：
$$
ak_1+bk_2=1\\
ak_3+bk_4=0\\
k_1 \equiv k_4 \\
k_2 \equiv k_3
$$
注意到这里有有关 $k$ 的限制。我们当然是需要一些只关于 $a$、$b$ 的充分必要的限制。所以我们考虑出发找一些必要条件。

只考虑前面的方程的话，这是两个互不相干的不定方程，所需条件为 $\gcd(a,b)=1$。

>如果这个条件充分，由于：
>$$
>ak_1+bk_2=1 \Rightarrow \begin{cases}k_1=x_0+nb\\k_2=y_0-na\end{cases}\\
>ak_3+bk_4=0 \Rightarrow \begin{cases}k_3=nb\\k_4=-na\end{cases}\\
>$$
>应该能构造出 $n_*$ 使得对于任意 $(a,b)|\gcd(a,b)=1$ 有：
>$$
>x_0+n_1b+n_2a \equiv 0\\
>y_0-n_1a-n_2b \equiv 0\\
>$$
>假设 $a \equiv b$，则：
>$$
>x_0+(n_1+n_2)a \equiv 0\\
>y_0-(n_1+n_2)a \equiv 0\\
>$$
>假设 $x_0 \not\equiv y_0$，则上式也就不成立了，故此条件不充分。

再考虑剩下两个式子，我们直接把方程模 $2$：
$$
(a-b)(k_1-k_2) \equiv 1\\
$$
显然要有 $a-b\equiv k_1-k_2 \equiv 1$。于是又导出一个限制：$a \not\equiv b \pmod {2}$。

此时我们发现，上面关于充分性的证伪中关键的一步被补充了。我们假设 $a$、$b$ 中是奇数的那个数是 $v$，则有如下证明：

> 类似前面的证明，有 $n_*$ 使得：
> $$
> x_0+n_1b+n_2a \equiv 0\\
> y_0-n_1a-n_2b \equiv 0\\
> $$
> 根据假设，式子变形为：
> $$
> x_0+n_xk \equiv 0\\
> y_0-n_yk \equiv 0\\
> $$
> 显然我们可以通过构造 $n_*$ 的值使得后半部分出现 $(x,y) \in \{0,1\} \times \{0,1\}$ 的所有可能，故上式成立。所以是充分的。

于是我们得到了充分必要条件：$\gcd(a,b)=1 \wedge a \not\equiv b$。

### 计数

于是计数就是：
$$
\sum_{a=1}^{n}\sum_{b \not\equiv a,1 \leq b \leq n}[\gcd(a,b)=1]\\
$$
或许会想直接拆解莫反，最后看起来直接整除分块了。但是这样有个问题，$d \equiv 1$ 不好搞。于是我们规避一下：
$$
\sum_{a=1}^{n}\sum_{b \not\equiv a,1 \leq b \leq n}[\gcd(a,b)=1]\\
=2\sum_{a=0}^{\lfloor\frac{n-1}{2}\rfloor}\sum_{b=1}^{\lfloor\frac{n}{2}\rfloor}[\gcd(2a+1,2b)=1]\\
$$

显然的一点是，奇数没有约数 $2$，故我们可以将 $2b$ 直接变为 $b$，规模减半。

于是我们有了一个新的思路：奇数转换为偶数。
$$
\sum_{a=0}^{\lfloor\frac{n-1}{2}\rfloor}\sum_{b=1}^{\lfloor\frac{n}{2}\rfloor}[\gcd(2a+1,b)=1]\\
=\sum_{b=1}^{\lfloor\frac{n}{2}\rfloor}\sum_{a=1}^{n}[\gcd(a,b)=1]-\sum_{b=1}^{\lfloor\frac{n}{2}\rfloor}\sum_{a=1}^{\lfloor\frac{n}{2}\rfloor}[\gcd(2a,b)=1]\\
=\sum_{b=1}^{\lfloor\frac{n}{2}\rfloor}\sum_{a=1}^{n}[\gcd(a,b)=1]-\sum_{b=0}^{\lfloor\frac{\lfloor\frac{n}{2}\rfloor-1}{2}\rfloor}\sum_{a=1}^{\lfloor\frac{n}{2}\rfloor}[\gcd(2b+1,a)=1]\\
$$
如果我们记 $f(n,m)=\sum_{a=0}^{\lfloor\frac{n-1}{2}\rfloor}\sum_{b=1}^{\lfloor\frac{m}{2}\rfloor}[\gcd(2a+1,b)=1]$，$s(n,m)=\sum_{b=1}^{n}\sum_{a=1}^{m}[\gcd(a,b)=1]$，则可以得到一个式子：
$$
f(n,m)=s(\lfloor\frac{m}{2}\rfloor,n)-f(\lfloor\frac{m}{2}\rfloor,n)
$$
可知：$f$ 会以指数级别降低，假设我们可以在 $O(T)$ 的时间计算 $f$，则可以 $O(T\log{n})$ 的算出 $f$。
$$
s(n,m)=\sum_{b=1}^{n}\sum_{a=1}^{m}[\gcd(a,b)=1]=\sum_{1 \leq d,d \leq n,d \leq m}\mu(d)\lfloor\frac{n}{d}\rfloor\lfloor\frac{m}{d}\rfloor
$$
杜教筛可以做到 $O(n^{2/3}+\sqrt{n})$。

总时间复杂度就是 $O(n^{\frac{2}{3}}+\sqrt{n}\log{n})$。

### 实现

```cpp
#include<bits/stdc++.h>
#define ul unsigned long long
#define int long long
const int B=1e7;
using namespace std;
int pri[B+5],cnt;
ul mu[B+5],s[B+5];
bool vis[B+5];
void init(){
    mu[1]=1;
    for(int i=2;i<=B;i++){
        if(!vis[i]){
            pri[++cnt]=i;
            mu[i]=-1;
        }
        for(int j=1;j<=cnt;j++){
            if(1ll*i*pri[j]>B)break;
            vis[i*pri[j]]=1;
            if(i%pri[j]==0)break;
            mu[i*pri[j]]=-mu[i];
        }
    }
    for(int i=1;i<=B;i++)s[i]=s[i-1]+mu[i];
}
unordered_map<int,int> mp;
ul summu(int n){
    if(n<=B)return s[n];
    if(mp.count(n))return mp[n];
    ul res=0;
    for(int l=2,r;l<=n;l=r+1){
        r=n/(n/l);
        res+=summu(n/l)*(r-l+1);
    }
    res=1-res;
    return mp[n]=res;
}
ul S(int n,int m){
    if(n>m)swap(n,m);
    ul res=0;
    for(int l=1,r;l<=n;l=r+1){
        r=min(n/(n/l),m/(m/l));
        res+=(summu(r)-summu(l-1))*(n/l)*(m/l);
    }
    return res;
}
ul f(int n,int m){
    if(!n||!m)return 0;
    return S(m/2,n)-f(m/2,n);
}
int T,n;
signed main(){
    init();
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    cin>>T;
    while(T--){
        cin>>n;
        cout<<f(n,n)*2<<'\n';
    }
}
```
